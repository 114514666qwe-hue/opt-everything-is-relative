## Section 4.2 COMPAS Reproduction

The Section 4.2 folder contains a static HTML report, generated figures, CSV
outputs, and scripts for rebuilding the COMPAS optimal-transport experiment.
The raw COMPAS CSV is not committed by default; the reproduction script downloads
it from ProPublica when run.
