Section 4.1

Everything is Relative: Understanding Fairness with Optimal Transport

Kwegyir-Aggrey, K., Santorella, R., Brown, S. M.  ·  arXiv:2102.10349v1

Setup

Blue College admits applicants from two secondary schools under a rule $r \in (0,1)$, the target admission fraction.

School ASchool B
Mechanism Deterministic constant score: $\mathcal{F}_1(a_i)=r,\;\forall i$ Dynamic quantile rule each year: $\mathcal{F}_2(b_j)=1$ for current-year GPA top $r\%$, else $0$
Pattern $\mathcal{F}$ constant vector at level $r$ binary vector induced by top-$r\%$ selection

Both schools share $P(Y=1)=r$, so the Disparate Impact 80% rule is not triggered:

$$\frac{P(Y=1\mid\text{School}=B)}{P(Y=1\mid\text{School}=A)} = 1 \;\not\leq\; \tau=0.8 \qquad\Longrightarrow\qquad \text{no disparate impact detected.}$$

Yet the admission patterns $\mathcal{F}_1$ and $\mathcal{F}_2$ are structurally different. We evaluate this gap via the OT-based Wasserstein-2 distance:

$$W_2(\mu_{\mathcal{F}_1},\mu_{\mathcal{F}_2}) =\sqrt{\min_{\pi}\langle \pi, C \rangle}, \qquad C_{ij}=\left|\mathcal{F}_1(a_i)-\mathcal{F}_2(b_j)\right|$$
Why does DI oscillate at the start?
The empirical DI is $\widehat{\tau}_t = \min(\hat{p}_{B,t}/\hat{p}_{A,t},\;1)$ with $\hat{p}_{A,t}=r$ fixed.
Early fluctuations come from finite-sample quantile selection in School B (the numerator), while clipping at 1 keeps DI in the legal range.

Simulation Code

def top_r_admissions(gpa, r):
    threshold = np.quantile(gpa, 1.0 - r)
    return (gpa >= threshold).astype(float)

def w2_ot_lp(F1, F2):
    n = len(F1)
    a = b = np.ones(n) / n
    C = np.abs(F1[:, None] - F2[None, :])  # C_ij = |F1_i - F2_j|
    pi = ot.emd(a, b, C)
    return float(np.sqrt(np.sum(pi * C))), pi, C

def simulate_year(rule, n, rng):
    y_A = rng.binomial(1, rule, n).astype(float)   # Bernoulli → DI
    p_A = y_A.mean()
    y_B = top_r_admissions(rng.uniform(GPA_MIN, GPA_MAX, n), rule)
    p_B = y_B.mean()
    di  = min(p_B / p_A, 1.0) if p_A > 1e-9 else 0.0
    F1  = np.full(n, rule)              # pattern: constant r
    w, _, _ = w2_ot_lp(F1, y_B)        # W2 via OT-LP
    return di, w

What do $\mathcal{F}_1$, $\mathcal{F}_2$, and $W_2$ mean?

In Section 4.1, the fairness patterns are defined directly at the individual level: $\mathcal{F}_1(a_i)=r$ for School A, and $\mathcal{F}_2(b_j)\in\{0,1\}$ for School B via yearly top-$r\%$ GPA selection.

DefinitionResulting $\mathcal{F}$
School A Constant admission probability for every individual $\mathcal{F}_1(a_i)=r,\;\forall i$
School B Top-$r\%$ GPA in that year gets score 1, others 0 $\mathcal{F}_2(b_j)=1$ if GPA$_j$ in top $r\%$, else $0$

The fairness gap is measured by OT with cost $C_{ij}=|\mathcal{F}_1(a_i)-\mathcal{F}_2(b_j)|$. This report computes the section's quantity directly using LP:

$$W_2(\mu_{\mathcal{F}_1},\mu_{\mathcal{F}_2}) = \sqrt{\min_{\pi}\langle\pi,C\rangle}, \qquad C_{ij}=|\mathcal{F}_1(a_i)-\mathcal{F}_2(b_j)|$$

The matrix view below visualizes $C$, the optimal coupling $\pi^*$, and the resulting $W_2$.

$$W_2(\mu_{\mathcal{F}_1},\mu_{\mathcal{F}_2}) =\sqrt{\sum_{i,j}\pi^*_{ij}\,C_{ij}}, \qquad \pi^*=\arg\min_{\pi\in\Pi(\mu_{\mathcal{F}_1},\mu_{\mathcal{F}_2})}\sum_{i,j}\pi_{ij}C_{ij}$$ 
# C_ij = |F1(a_i) - F2(b_j)|  (each student is a point in pattern space)
F1     = np.full(n, r)                    # School A: constant r
F2     = top_r_admissions(gpa, r)         # School B: 0 or 1
C      = np.abs(F1[:, None] - F2[None, :])  # n x n cost matrix
a = b  = np.ones(n) / n                   # uniform marginals
pi_star = ot.emd(a, b, C)                 # OT-LP solution
W2     = np.sqrt(np.sum(pi_star * C))     # Wasserstein-2
Because School A assigns the same score $r$ to every individual, rows of $C$ are identical. The optimal $\pi^*$ concentrates mass on minimum-cost entries.
